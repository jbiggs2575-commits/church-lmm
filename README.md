# Grace Community Church

A responsive church website starter built with HTML, CSS, and Bootstrap 5.

## Pages

- `index.html` — welcome page, Sunday service times, and a ministry preview
- `html/about.html` — church story and values
- `html/products.html` — kids, groups, and serving ministries
- `html/contact.html` — Sunday visit details and contact information

## Run locally

Open `index.html` in a browser. Bootstrap, fonts, and photography are loaded from external CDNs, so an internet connection is needed for those assets.

## Customize before publishing

Replace the sample church name, service times, address, email, and phone number across the HTML pages with the church's real details. Update the Google Maps directions link and replace the sample photos as desired. The contact details are examples; this static site does not include a form backend.
